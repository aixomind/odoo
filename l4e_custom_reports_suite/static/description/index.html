1. Setup & Company Branding

Configure paper formats, upload company header/footer banners, customize live color themes, and enable your official company seal.

1. Paper Format Setup
2. Header & Footer Banners
3. Dynamic 3-Color Theme
4. Master Company Stamp

Step 1: In Settings > Document Layout > Configure Document Layout, choose A4 - L4E Signature Layout. This sets optimal top margins (42mm) and bottom margins (45mm) to guarantee zero overlapping.

Step 2: In Settings > Companies > Report Header & Footer, upload company header and footer banners. Recommended high-resolution size is 1024 x 122 px (or 2048 x 244 px for 300 DPI ultra-crisp printouts).

Step 3: Customize Report Text Color, Table Header Background Color, and Banner Background Color using live color pickers. Includes a 1-Click Reset to Default Colors button anytime.

Step 4: Check "Enable Company Stamp/Seal" and upload your official transparent stamp/seal image. Each company in a multi-company database can maintain its own distinct seal.

Frequently Asked Questions
Quick answers to common questions.
What is the recommended size for Header and Footer banner images?
The standard recommended size is 1024 x 122 px (or 2048 x 244 px for ultra-high-resolution 300 DPI print quality). This matches standard A4 width margins perfectly without stretching.
Do I need to modify any Python or XML code to use this?
No coding is required. Everything is configured through standard Odoo user interfaces (Company settings, Document Layout, and order form tabs).
Does this work with Multi-Company environments?
Yes! Each company in your database can have its own distinct header/footer banners, individual color themes, and unique official company stamp.
Can I reset colors back to default anytime?
Yes! Simply click the "Reset to Default Colors" button in Company settings to restore standard default colors instantly.
