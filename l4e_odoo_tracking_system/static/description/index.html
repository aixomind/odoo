Odoo's Default Tracking Is Hard to Read — and Deleted Records Are Gone Forever

Odoo's built-in chatter logs field changes as dense bullet-point lists. When Order Lines change, the entire old list and new list are pasted side by side — making it nearly impossible to spot what actually changed at a glance.

Smart Chatter Tracking & Dust Bin solves both: crystal-clear green tracking cards that show only what changed, and a safety-net Dust Bin that lets admins restore any deleted record in one click.

Comprehensive Feature List

Two powerful features, one lightweight module — zero configuration overhead.

Custom Green Tracking Cards

Every field change posts a clean, colour-coded card in the chatter — field name in bold green, old value in red, new value in bright green.

Order Lines Diff (Added / Removed)

For Order Lines and any many2many/one2many field, the card shows only what was added or removed — not the entire list twice. Unchanged items are summarised as "X items unchanged".

Orange Empty-Field Highlight

When a field is cleared or was previously empty, a vivid orange "empty" label is shown so nobody misses it — no more invisible blank-to-value or value-to-blank changes.

Per-Model On/Off Toggle

Enable tracking on any Odoo model independently — Sales Orders, Invoices, Contacts, Purchase Orders, and more. Mutually exclusive toggles ensure no conflicting configuration is ever saved.

Dust Bin — Deleted Record Safety Net

Every deleted record from a tracked model is automatically snapshotted and stored in the Dust Bin with its full field data, deletion timestamp, and original model reference.

One-Click Admin Restore

System Administrators can select one or more Dust Bin records and click Restore — the record is recreated in the original model and removed from the Dust Bin automatically.

Configurable Retention Period

Set a Tracking Days limit per model — Dust Bin entries older than that limit are purged automatically by a scheduled cron job. Set to 0 for unlimited retention.

Admin-Restricted Restore

Only System Administrators can restore Dust Bin records, preventing accidental or unauthorised data recovery. Regular users can view the Dust Bin but cannot restore.

Dark Mode Support

The custom tracking cards come with a dedicated dark mode stylesheet so they look sharp whether the user is on Odoo's light or dark theme.

How It Works

A step-by-step visual walkthrough of the module in action.

1 Open Configure Tracking from the Menu

After installing the module, a new Tracking System menu appears in Odoo. Under it you'll find Configure Tracking and Dust Bin Data. Go to Configure Tracking to set up which models to track.

2 Enable Tracking on Any Model

Create a new tracking configuration, select the model (e.g. Sale Order), and toggle Tracking Enable. The two boolean fields are mutually exclusive — enabling one automatically locks the other, so you can never have a conflicting setup. Set Tracking Days to control how long deleted records stay in the Dust Bin (0 = unlimited).

3 Edit a Record — Watch the Chatter Transform

Open any Sales Order and make a change — update the customer, payment terms, or salesperson. Instead of a plain bullet-point log, the chatter now shows a custom green tracking card: the field name in bold green, the old value in red, and the new value in bright green. Every single field change gets its own card, making the history crystal clear.

4 Order Lines — See Only What Changed, No Repetition

When you add or remove a product from the order lines, the tracking card shows a clean diff: Added lines in green, Removed lines in red, and a compact X items unchanged summary — no more scrolling through both the old and new full list to figure out what moved.

Adding a second product to the same order shows the diff again — this time with 1 item unchanged summarised in orange, so it's immediately clear how many lines already existed.

5 Empty Fields Are Never Invisible Again

When a field is set for the first time (was previously empty), or cleared to blank, the card renders a vivid orange "empty" label instead of showing nothing. Empty-to-value and value-to-empty changes are now immediately obvious in the audit trail.

6 Delete a Record — It Goes to the Dust Bin Automatically

When any record from a tracked model is deleted, the module automatically captures a full data snapshot and stores it in Dust Bin Data — including the record name, original model, deletion date, and all field values at the time of deletion. No manual action needed.

7 Restore Deleted Records in One Click

System Administrators can open any Dust Bin entry to view the full field snapshot, then click the Restore button. The record is immediately recreated in the original model with all its original data, and the Dust Bin entry is cleared automatically. Bulk restore is also supported — select multiple records from the list and restore them all at once.
