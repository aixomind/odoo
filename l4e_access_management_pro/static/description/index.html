Comprehensive Access Control Features

Everything you need to secure your enterprise Odoo instance.

Global System Toggles

Instantly restrict core system capabilities across target users:

  • Disable Login: Lock account access instantly.
  • Disable Debug Mode: Block developer mode access.
  • Global Read-Only: Enforce view-only rights.
  • Disable Export & Import: Prevent data leaks.

Model-Level Rights

Configure granular CRUD permissions per model for targeted users or groups:

  • Read, Create, Write, & Delete permissions.
  • Restrict Archive & Unarchive actions.
  • Disable Record Duplication & Copying.
  • Block Export on specific models.

Field Level Restrictions

Control visibility and editability of sensitive fields on any form view:

  • Invisible: Hide sensitive fields & labels completely.
  • Read-Only: Prevent editing sensitive values.
  • Required: Enforce mandatory data entry per user.
  • Auto-hides corresponding table headers & labels.

Button & Tab Hiding

Clean up form views by hiding or disabling specific action buttons and notebook tabs:

  • Hide workflow buttons (Confirm, Cancel, Approve).
  • Disable specific action buttons without XML edit.
  • Hide entire notebook tabs (e.g. Other Info, Accounting).
  • Target elements by technical name or string label.

Chatter Restrictions

Control interaction and visibility inside the Odoo mail chatter area:

  • Hide Send Message button.
  • Hide Log Note button.
  • Hide Schedule Activity button.
  • Hide Followers & Attachments buttons.

Menu & Report Hiding

Simplify navigation and safeguard confidential PDF print reports:

  • Hide top apps, menus, and submenus cleanly.
  • Restrict PDF print reports from the Print dropdown.
  • Hide custom filters and group-by search options.
  • Company & User group scoping supported.
