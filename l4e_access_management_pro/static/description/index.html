Frequently Asked Questions
Quick answers before you buy.
Why should I buy this app? Odoo already has access management.
You're right that Odoo has its own access rights system, but it requires configuration in several different places to hide a single field or button. Access Management Pro centralizes everything — menus, models, fields, buttons, chatter, and domains — in one dashboard, with no technical expertise required.
Can I restrict elements conditionally?
Yes. Domain access rights let you apply conditional restrictions based on field values, so for example a salesperson can be limited to seeing only their own orders.
