Universal Field Update & Model Explorer

The ultimate database administration tool to safely inspect, search, and bulk update any field on any Odoo model — with full audit trails!

Stop Writing One-Off Scripts to Fix Your Data

Every growing Odoo database eventually needs a correction that standard views were never built for — a salesperson reassigned across thousands of leads, a discontinued product swapped out everywhere it's referenced, a mis-mapped selection value left over from a data migration, or a duplicate partner that needs to be merged into the correct one across dozens of unrelated modules. Doing this by hand means opening every record one at a time, or asking a developer to write and run a one-off script in the Odoo shell — risky, slow, and impossible to audit afterwards.

Universal Field Update replaces that risk with a guided, permission-controlled wizard. Pick any model and any field, define the current and replacement values, preview exactly which records will be touched, and apply the change with a single click — while every execution is written to a permanent, sequential audit log for full accountability.

Module Features

Any Model, Any Field

Dynamically select any installed model and any stored field — text, numeric, boolean, selection, date, datetime, or Many2one — with automatic type detection.

Interactive Review Grid

The wizard populates a grid of matching records (up to a 1,000 record preview). Visually review and deselect anything that shouldn't be touched.

Secondary Filter Field

Narrow a wide match down to an exact subset by adding an optional second field/value filter before the search runs.

Global Reference Replace

Pick a reference record — like a Partner or User — and scan every model in the database that points to it, so you can replace it everywhere in one shot.

Force Update (Guarded)

An optional SQL-level bypass writes directly around locked or posted document guards for the rare cases that truly need it — hidden behind the Manager security group.

Permanent Audit Log

Every run creates a sequential log entry recording records requested, updated, skipped, and failed — with per-record error detail for full traceability.
